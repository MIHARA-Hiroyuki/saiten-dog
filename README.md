# 採点DOG(Digital Offline Grading) v1.02

スキャンした答案を、問題ごとに全員分並べて採点するデジタル採点支援システムです。

- **使う**:このページの公開URL(`https://ユーザー名.github.io/saiten-dog/`)を Chrome か Edge で開くだけで使えます。インストールは不要です。
- **オフラインで動きます**:答案の読み込みから採点・集計・印刷まで、開いているパソコンのブラウザの中だけで処理します。答案の画像・氏名・採点結果をインターネット上のどこにも送りません。インターネットを使うのは、このページを読み込むときだけです。
- **操作マニュアル**:[manual_v1.02.pdf](manual_v1.02.pdf)
